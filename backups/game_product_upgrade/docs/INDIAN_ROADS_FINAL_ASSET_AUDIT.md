## 3. Scale Normalization Verification

To ensure high-resolution assets (1200px – 2000px) do not overpower the 2D side-scrolling camera:
1. `Landmark.gd`: Normalizes monument textures with `tex.get_height() > 500` via dynamic factor `scale_factor *= (300.0 / float(tex.get_height()))`. Milestone sprite scale normalized to 50px height.
2. `IndianRoadTerrain.gd`: Uses `_add_roadside_sprite(tex, target_height, pos_x, road_y, z_idx)` to clamp all high-DPI sprites (trees, dhabas, tea stalls, signs, cones) to exact gameplay pixel proportions touching the tarmac.
3. `Checkpoint.gd` & `FinishArch.gd`: Clamps gate stanchions, banners, and finish arches to target heights (180px, 60px, 240px respectively).

All 17 automated project test suites pass with 100% success.
